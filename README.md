# iac-boldyrev

Практические (`work-*`) и домашние (`hw-*`) работы по предмету **«Инфраструктура как код»**, вариант 04. Стенды в Yandex Cloud создаются и удаляются Bash-скриптами; настройка nginx автоматизирована через cloud-init.

| Каталог | Содержание |
| --- | --- |
| [work-01](work-01/) | Практическая №1: создание сети, подсети и двух ВМ через CLI; журнал ручной настройки ВМ и nginx — `notes.md`, команды — `commands.sh`. |
| [work-02](work-02/) | Практическая №2: три ВМ в двух зонах, дополнительный диск и сетевой балансировщик. `create.sh` — основной вариант; `create-independent.sh` — самостоятельная часть с параметрами числа ВМ и размера диска, монтированием в `/mnt/data`. |
| [hw-01](hw-01/) | Домашняя №1: веб-серверы за балансировщиком, сервер приложения без публичного IP, NAT-шлюз и маршрутизация; проверки HTTP, балансировки и доступа к приложению. |

Для запуска нужны Bash, настроенный [Yandex Cloud CLI](https://yandex.cloud/ru/docs/cli/quickstart) (`yc init`, выбор облака и каталога с правами на создание ресурсов), `jq`, `envsubst` (GNU gettext), `curl` и SSH-ключ `~/.ssh/id_ed25519` с публичной частью `.pub`.

Все команды выполняются **из корня репозитория**. Выберите одну работу:

| Стенд | Создать | Удалить |
| --- | --- | --- |
| Практическая №1 | `bash work-01/create.sh` | `bash work-01/destroy.sh` |
| Практическая №2 | `bash work-02/create.sh` | `bash work-02/destroy.sh` |
| Самостоятельная часть №2 | `bash work-02/create-independent.sh 3 20` (3 ВМ, диск 20 ГБ) | `bash work-02/destroy-independent.sh` |
| Домашняя №1 | `bash hw-01/create.sh 3` (3 веб-сервера) | `bash hw-01/destroy.sh` |

В №2 и домашней №1 дождитесь завершения cloud-init и откройте `http://<публичный IP балансировщика>`: ожидается `devlab on <имя ВМ>`. Домашний стенд проверяется командой `bash hw-01/check.sh 3` (число должно совпадать с указанным при создании).

Работы используют общий префикс ресурсов `boldyrev-04`: запускайте их по очереди, удаляя предыдущий стенд. Параметры и зоны заданы в начале скриптов. После работы удалите стенд, чтобы прекратить начисления за ресурсы.
